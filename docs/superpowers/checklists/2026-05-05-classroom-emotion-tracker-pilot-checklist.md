# 파일럿 운영 체크리스트 (우리 반 마음 날씨 예보관)

**목적:** 수업에서 바로 사용할 수 있게, 실제 동작 기준으로 점검합니다.  
**대상:** 교실 전자칠판(브라우저 기반 단일 앱)  
**버전 기반 확인일:** 2026-05-05

## 1) 배포/접속 확인

- [ ] 오늘 사용할 링크(배포 URL 또는 로컬)에서 화면이 정상 진입되는지 확인합니다.
- [ ] 상단에 `오늘의 교실 마음 날씨` / 오늘 날짜·참여자 수가 표시되는지 확인합니다.
- [ ] 새로고침해도 앱이 다시 열리고 바로 사용 화면이 나오는지 확인합니다.
- [ ] 브라우저가 동일한 출처(동일한 URL)에서 동작하는지 확인합니다.  
  - 교실 PC, 전자칠판 브라우저를 바꾸면 새로 시작됩니다.
- [ ] 배포된 화면에서 모달(교사용 PIN 입력, 날씨 선택 패널)이 뜨면 닫기(×)가 동작하는지 확인합니다.

## 2) 학생 체크인 기본 흐름 확인

- [ ] 학생 번호 버튼(예: `1번`)을 눌렀을 때 날씨 선택 패널이 열리는지 확인합니다.
- [ ] `☀️ 좋아요`, `⛅ 조금 흐려요`, `🌧️ 속상해요`, `⚡ 화가 나요/긴장돼요` 중 하나를 선택하면 패널이 닫히는지 확인합니다.
- [ ] 선택 후 해당 학생 카드가 `선택 완료`로 바뀌고, 교실 통계가 즉시 갱신되는지 확인합니다.
- [ ] 일반 화면에서는 개별 이모지가 보이지 않고(오직 완료/대기만), 선생님 모드에서만 개별 이모지/상세가 보이는지 확인합니다.
- [ ] 같은 학생이 다시 선택하면 최신 선택값으로 변경되는지(덮어쓰기) 확인합니다.

## 3) 선생님 PIN 설정/재진입 확인

- [ ] 교실 운영 전 `교사용` 버튼으로 진입 시, 최초에는 **처음 사용할 PIN 설정** 모달(`처음 사용할 PIN 설정`)이 뜨는지 확인합니다.
- [ ] 새 PIN과 확인 PIN이 모두 4자리 숫자인지, 서로 다르면 `PIN 확인이 서로 달라요.` 메시지가 뜨는지 확인합니다.
- [ ] `PIN 설정` 완료 후 `선생님 모드`가 열려서 번호별 오늘 이모지가 보이는지 확인하고, 개별 학생의 7일 흐름은 학생 번호를 선택한 뒤에만 확인되는지 확인합니다.
- [ ] 설정 후 브라우저 새로고침 후, 다시 `교사용`을 눌렀을 때 **PIN 입력** 모달만 나오고 `새 PIN` 입력이 아닌지 확인합니다.
- [ ] 잘못된 PIN 입력 시 `PIN이 맞지 않아요.` 메시지로 즉시 차단되는지 확인합니다.
- [ ] 올바른 PIN 입력 시 바로 `선생님 모드`로 재진입되는지 확인합니다.

## 4) 교사용 잠그기(교사 재잠금) 확인

- [ ] 선생님 모드에서 `교사용 잠그기` 버튼이 보이는지 확인합니다.
- [ ] 누르면 즉시 교사용 모드가 닫히고, 설정/학생 상세 영역이 사라지는지 확인합니다.
- [ ] 잠근 뒤 학생 화면은 다시 번호/완료 여부만 보이는지 확인합니다.
- [ ] 잠그기 후 PIN 해제가 다시 필요하고, 이전 설정은 유지되는지(학급 인원·저장 PIN) 확인합니다.

## 5) 오늘 기록 초기화 확인

- [ ] 선생님 모드 → `설정 열기` → `오늘 기록 초기화` 노출 여부를 확인합니다.
- [ ] 버튼 클릭 시 확인 다이얼로그가 반드시 표시되는지 확인합니다.
  - 문구: `오늘 기록을 모두 초기화할까요?`
- [ ] 확인(`확인`) 시 오늘 참여수(`0명`)와 버튼 표시가 초기화되는지 확인합니다.
- [ ] 취소(`취소`) 시 오늘 기록이 유지되는지 확인합니다.
- [ ] 기록 초기화는 오늘 날짜만 대상인지(과거 7일 이력은 유지) 확인합니다.

## 6) localStorage 기반 운영 주의사항

- [ ] 이 앱은 `localStorage`만 사용합니다. 브라우저 저장공간이 같은 경우에만 데이터가 유지됩니다.
  - 저장 키: `classroom-emotion-tracker-state`
- [ ] 브라우저 캐시/사이트 데이터 초기화, 시크릿 탭, 다른 브라우저/기기 이동 시 기록이 사라지므로 같은 브라우저/프로필/스토리지 컨텍스트에서만 유지되는 점을 숙지합니다.
- [ ] 앱 내 PIN 복구 기능은 제공되지 않으므로, 수업 전 선생님이 PIN을 별도 메모로 관리하세요.
- [ ] 잘못된 저장값/파손된 데이터 복구 시 앱이 기본값(20명, PIN 미설정)으로 시작할 수 있으므로, 첫 화면이 기본 상태로 돌아오면 학급인원 설정값과 PIN 설정 상태, 그리고 7일/오늘 기록 유지를 즉시 점검합니다.
- [ ] 데이터 보존 정책은 7일 이력까지만 유지입니다. 과거 이력은 자동 삭제됩니다.

## 7) 전자칠판/터치 사용 전 최종 점검

- [ ] 시작 화면에서 버튼 크기와 간격이 터치 오인식 없이 눌리는지 확인합니다(학급 전체 화면 비율 1교시 전에 점검).
- [ ] 학생 번호 1~현재 설정 인원(기본 20명)까지 모두 보이는지 확인하고, 필요 시 설정에서 인원을 맞춥니다.
- [ ] 터치 미동작/반응 지연이 있으면 브라우저 확대(줌) 대신 화면 크기 맞춤/브라우저 재시작으로 해결합니다.
- [ ] 연속 사용 중 화면을 바꿀 일 없이, 교사용 화면은 `설정 열기`를 눌렀을 때만 펼치고 마감합니다.

## 8) 수업 중 문제 발생 시 빠른 대응

- [ ] 학생이 선택이 안 된다면: 모달이 떠 있는지 확인 후 ×로 닫고 다시 시도합니다.
- [ ] 특정 번호가 보이지 않거나 번호 수가 맞지 않으면: 선생님 모드 진입 후 설정에서 학급 인원(1~40) 재확인/수정합니다.
- [ ] 통계가 이상하면: 브라우저 새로고침 후 번호 버튼의 완료/대기 표시 개수, 참여 수치(`완료/총원`), 번호별 `선택 완료` 표시를 함께 확인합니다.
- [ ] PIN 해제 불가 시: 오타/자릿수 부족 여부 확인 후 다시 입력하고, 계속 안 되면 교사가 PIN 분실 가능성을 먼저 점검합니다.
- [ ] 최후 수단: 브라우저 저장소(`localStorage`) 삭제는 앱 상태 전체를 파괴(저장 PIN, 학급 인원, 최근 7일 기록, 오늘 기록까지 모두 삭제)하므로, 실제 수업 재개 전 최후 수단으로만 실행하고 “초기 상태로 시작” 공지를 먼저 남긴 뒤 진행합니다.

## 종료 확인

- [ ] 오늘 수업 종료 전 `교사용 잠그기`로 학생 화면만 남도록 마무리합니다.
- [ ] 문제 발생 로그(교사용 메모)와 초기화 여부를 다음 수업 시작 전에 본인 메모로 정리해 둡니다.
