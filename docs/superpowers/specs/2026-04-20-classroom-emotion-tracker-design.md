# 우리 반 마음 날씨 예보관 설계

## 개요

“우리 반 마음 날씨 예보관”은 아침 조회 시간이나 상담 전에 학생들이 자신의 감정 상태를 날씨 이모지로 표현하고, 선생님이 학급 전체 분위기와 도움이 필요한 신호를 자연스럽게 확인할 수 있도록 돕는 단일 브라우저 앱이다.

대상은 전 학년이며, 도덕 및 창의적 체험활동에서 `[4도01-01] 자신의 감정을 바르게 이해하고 상황에 맞게 표현하며, 긍정적인 생활 태도를 지닌다`와 연결해 사용할 수 있다.

## 목표

- 학생이 자신의 번호를 눌러 오늘의 마음 날씨를 빠르게 선택한다.
- 전자칠판 기본 화면에서는 학급 전체 통계와 선택 현황을 보여준다.
- 개별 학생의 감정값과 최근 7일 흐름은 4자리 PIN을 통과한 선생님 모드에서만 보여준다.
- 모든 기록은 브라우저 로컬 저장소에만 저장해 서버 전송 없이 교실 PC에서 사용할 수 있게 한다.

## 핵심 결정

- 구현 형태: React 기반 단일 브라우저 앱
- 저장 방식: `localStorage`만 사용
- 학생 표시: 이름 없이 번호만 표시
- 기본 인원: 20명
- 인원 범위: 설정에서 1명부터 40명까지 변경 가능
- 기본 레이아웃: 통계 먼저 보기
- 시각 톤: 부드러운 교실형
- 감정 선택지: `☀️ 좋아요`, `⛅ 조금 흐려요`, `🌧️ 속상해요`, `⚡ 화가 나요/긴장돼요`
- 기록 범위: 최근 7일
- 보호 방식: 선생님 모드는 4자리 PIN으로 보호

## 사용자 흐름

### 학생 흐름

1. 학생은 전자칠판에서 자신의 번호 카드를 누른다.
2. 화면 중앙의 큰 날씨 선택 패널에서 오늘의 마음 날씨를 고른다.
3. 선택이 저장되고, 번호 카드는 일반 화면에서 “선택 완료” 상태로 바뀐다.
4. 학급 통계는 즉시 갱신된다.
5. 같은 학생이 다시 선택하면 오늘의 날씨가 새 값으로 변경된다.

### 선생님 흐름

1. 선생님은 “선생님 모드” 버튼을 누른다.
2. 첫 사용이면 새 4자리 PIN을 설정한다.
3. PIN이 이미 설정되어 있으면 4자리 PIN을 입력한다.
4. PIN이 맞으면 개별 번호별 오늘의 날씨가 표시된다.
5. 선생님은 특정 번호를 눌러 해당 학생의 최근 7일 마음 날씨 흐름을 확인한다.
6. 설정 패널에서 학급 인원과 PIN을 변경할 수 있다.

## 화면 구성

### 오늘 통계

전자칠판 첫 화면의 중심 영역이다. 오늘 선택된 마음 날씨의 분포를 원형 차트와 숫자 요약으로 보여준다. 미선택 학생 수를 함께 표시해 아침 조회 중 참여 현황을 바로 확인할 수 있게 한다.

### 학생 번호 격자

학생 번호를 1번부터 현재 학급 인원까지 격자로 보여준다. 일반 화면에서는 개별 감정 이모지를 숨기고, 선택 완료 또는 미선택 상태만 보여준다. 선생님 모드에서는 번호 카드에 오늘의 날씨 이모지를 함께 표시한다.

### 날씨 선택 패널

번호를 누르면 큰 버튼 4개가 표시된다. 각 버튼에는 이모지와 짧은 감정 설명을 함께 둔다.

- `☀️ 좋아요`
- `⛅ 조금 흐려요`
- `🌧️ 속상해요`
- `⚡ 화가 나요/긴장돼요`

패널은 취소할 수 있어야 하며, 선택 후에는 바로 닫힌다.

### 선생님 PIN 모달

선생님 모드 진입 전에 4자리 PIN을 입력받는다. 첫 사용이라 PIN이 없으면 새 PIN 설정 화면을 먼저 보여준다. 입력 실패 시에는 “PIN을 다시 확인해 주세요.”처럼 다음 행동이 분명한 오류 문구를 보여준다. PIN 변경은 선생님 모드 안의 설정에서만 가능하다.

### 선생님 상세

PIN 해제 후 표시되는 영역이다. 개별 번호별 오늘의 날씨와 학생별 최근 7일 흐름을 보여준다. 학생별 7일 흐름은 특정 번호를 선택했을 때만 표시해 화면을 복잡하게 만들지 않는다.

### 설정 패널

선생님 모드에서만 열 수 있다.

- 학급 인원: 1-40명
- PIN 변경: 현재 PIN 확인 후 새 4자리 PIN 저장
- 오늘 기록 초기화: 실수로 입력한 날의 기록을 지울 수 있는 기능

기록 초기화는 즉시 실행하지 않고 확인 절차를 둔다.

## 데이터 모델

모든 데이터는 `localStorage`에 하나의 앱 상태로 저장한다.

```ts
type WeatherType = "sunny" | "cloudy" | "rainy" | "stormy";

type DailyWeatherRecord = {
  date: string;
  entries: Record<string, WeatherType>;
};

type AppSettings = {
  studentCount: number;
  teacherPin: string | null;
};

type AppState = {
  settings: AppSettings;
  records: DailyWeatherRecord[];
};
```

`date`는 한국 시간 기준의 `YYYY-MM-DD` 문자열이다. 앱을 열 때마다 오늘을 포함한 최근 7일 기록만 남기고 오래된 날짜는 자동으로 정리한다.

## 저장 및 정리 규칙

- 첫 실행 시 기본 상태를 만든다.
- 기본 학생 수는 20명이다.
- 기본 PIN은 `null`이다. 선생님 모드를 처음 열 때 새 4자리 PIN을 설정해야 하며, PIN 설정 전에는 개별 학생 기록을 보여주지 않는다.
- 오늘 날짜의 기록이 없으면 빈 기록을 만든다.
- 학생 번호가 현재 학급 인원보다 커진 기록은 삭제하지 않는다. 학급 인원을 줄였다가 다시 늘릴 수 있기 때문이다.
- 통계 계산은 현재 학급 인원 범위 안의 번호만 대상으로 한다.
- 최근 7일보다 오래된 기록은 앱 시작 시 제거한다.

## 개인정보 및 공개 범위

일반 화면은 학급 활동용 화면이다. 개별 학생의 감정 이모지는 기본적으로 숨긴다. 선생님 모드에서만 개별 감정과 학생별 7일 흐름을 보여준다.

서버 저장, 클라우드 동기화, 로그인, 이름 입력은 첫 버전 범위에 포함하지 않는다. 감정 데이터는 브라우저 저장소에만 남는다.

## 접근성 및 디자인 기준

최신 Web Interface Guidelines 기준을 따른다.

- 클릭 가능한 요소는 `<button>`을 사용한다.
- 아이콘만 있는 버튼에는 `aria-label`을 둔다.
- 폼 입력에는 `<label>` 또는 `aria-label`을 둔다.
- 포커스 상태는 `:focus-visible`로 명확히 보이게 한다.
- 통계 변화처럼 중요한 상태 변화는 필요 시 `aria-live="polite"`로 알린다.
- 애니메이션은 `transform`과 `opacity` 중심으로 제한한다.
- `prefers-reduced-motion`을 존중한다.
- 숫자 통계는 `font-variant-numeric: tabular-nums`를 적용한다.
- 긴 텍스트가 버튼이나 카드 밖으로 넘치지 않게 한다.
- 전자칠판 터치 사용을 고려해 버튼과 카드의 터치 영역을 충분히 크게 만든다.

## 테스트 계획

### 단위 테스트

- 기본 상태 생성
- 학생 수 범위 검증
- 오늘 날짜 기록 생성
- 학생 날씨 선택 및 변경
- 오늘 통계 계산
- 최근 7일 기록 정리
- 현재 학급 인원 범위만 통계에 포함
- PIN 검증

### 브라우저 스모크 테스트

- 번호 선택 후 날씨 패널이 열린다.
- 날씨를 선택하면 오늘 통계가 즉시 바뀐다.
- 일반 화면에서는 개별 날씨가 숨겨진다.
- 잘못된 PIN 입력 시 오류가 표시된다.
- 올바른 PIN 입력 후 개별 날씨와 학생별 7일 흐름이 보인다.
- 학급 인원을 변경하면 번호 격자가 1-40명 범위에서 갱신된다.
- 오늘 기록 초기화는 확인 후에만 실행된다.

## 완료 기준

- 교실 전자칠판에서 앱을 열고 학생들이 번호를 눌러 마음 날씨를 선택할 수 있다.
- 선생님은 기본 화면에서 전체 분위기와 미선택 학생 수를 확인할 수 있다.
- 선생님은 PIN을 입력한 뒤 개별 학생의 오늘 상태와 최근 7일 흐름을 확인할 수 있다.
- 기록은 브라우저 로컬 저장소에만 남으며 최근 7일로 정리된다.
- 접근성, 터치 사용성, 반응형 레이아웃 기준을 만족한다.

## 첫 버전 범위 밖

- 학생 이름 입력
- 캐릭터 배정
- 클라우드 저장
- 여러 기기 동기화
- 계정 로그인
- CSV 또는 엑셀 내보내기
- 학생별 자유 문장 입력
- 푸시 알림
