# 릴리스 노트: 2026-05-05 파일럿 운영 보강

## 요약

이번 업데이트는 교실 파일럿 운영 직전에 필요한 보완을 묶은 릴리스입니다.  
핵심은 `교사용 잠그기` 추가, PIN 재진입과 초기화 흐름 안정화, 그리고 실제 수업 전에 바로 확인할 수 있는 체크리스트 제공입니다.

## 포함된 변경

### 1. 교사용 잠그기 추가

- 선생님 모드에서 `교사용 잠그기` 버튼으로 즉시 학생 화면으로 돌아갈 수 있습니다.
- 잠그는 즉시 교사용 설정 패널과 선택 학생 상세가 함께 닫혀, 개별 감정 정보가 바로 숨겨집니다.
- 저장된 PIN과 학생 기록은 유지되며, 다시 들어갈 때는 기존 PIN 입력이 필요합니다.

### 2. 교사용 흐름 및 회귀 테스트 보강

- 새로고침 후에도 저장된 상태가 복원되는지 확인하는 테스트를 추가했습니다.
- `오늘 기록 초기화`가 확인/취소에 따라 올바르게 동작하는지 검증을 보강했습니다.
- `오늘 기록 초기화`가 오늘 기록만 지우고, 최근 7일 범위 안의 이전 기록은 유지하는지 자동화 검증을 추가했습니다.
- 교사용 재잠금 후 재진입, 잘못된 PIN 차단, 올바른 PIN 재언락 흐름을 브라우저 테스트로 확인했습니다.

### 3. 파일럿 운영 자료 추가

- 수업 직전에 바로 사용할 수 있는 파일럿 점검 문서를 추가했습니다.
- 체크리스트 문서:
  [2026-05-05-classroom-emotion-tracker-pilot-checklist.md](../superpowers/checklists/2026-05-05-classroom-emotion-tracker-pilot-checklist.md)

## 검증

이번 파일럿 보강 범위는 아래 검증을 통과했습니다.

- `vitest run`
- `tsc -b`
- `vite build`
- `playwright test --config=playwright.local.config.mjs`

## 운영 메모

- 이 앱은 `localStorage` 기반이라 같은 브라우저/프로필/저장공간에서만 데이터가 이어집니다.
- 브라우저 저장소를 비우면 PIN, 학급 인원, 오늘 기록, 최근 7일 기록이 함께 사라집니다.
- 실제 수업 전에는 체크리스트 문서 기준으로 `교사용 잠그기`, `PIN 재진입`, `오늘 기록 초기화`만 한 번씩 확인해 두시는 것을 권장합니다.
